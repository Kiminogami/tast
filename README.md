# Simple Interest Calculator

A command-line calculator written in Bash for the IBM Introduction to Git and GitHub final project. The script prompts for a principal amount, an annual interest rate, and a time period, then calculates the simple interest earned.

## Usage

From the repository directory, run:

```bash
bash simple-interest.sh
```

Enter the following values when prompted:

- **Principal** — the original amount of money.
- **Interest rate** — the annual rate as a percentage. Enter `5` for 5%.
- **Time period** — the number of years.

## Formula

```text
Simple interest = (principal × annual interest rate × time in years) / 100
```

For example, a principal of 1,000 at 5% per year for 2 years earns 100 in simple interest.
